# Independently recheck the correction

## Input
Original note, acceptance criterion and new encoded version.

## Source
https://help.frame.io/en/articles/9952618-comparison-viewer

## Output
Recheck evidence against the exact version.

## Check
Compare outputs; close only when the criterion is met. A different reviewer supplies the independent check.

## Fallback
Return to report-note if the criterion still fails.
